# Facelet: scope

**Facelet** (a *facelet* is one sticker position on a cube) is a private, open, fast speedcubing
suite built around the 3x3. Everything runs locally in the browser. Nothing is ever sent to a
server: no accounts, no analytics, no third-party requests. Data lives in IndexedDB on the user's
device and can be exported or imported at any time.

Design language: monochrome. Black, white and greys only, light theme by default (dark optional).
The only colour on screen is the cube itself (scramble previews, virtual cube, case images).
Typography-led layout, generous whitespace, subtle motion, a tasteful celebration on new PBs.

---

## 1. Timer (primary)

- **Spacebar timing**: hold to arm (configurable hold time), release to start, any key to stop.
  Touch screens: hold anywhere on the timer area. Esc cancels.
- **WCA inspection** (optional): 15 s countdown, 8 s / 12 s alerts (voice or beep), automatic
  +2 at ≥15.00 s and DNF at ≥17.00 s (Regulation A4d).
- **Penalties**: OK / +2 / DNF on any solve, from buttons or keyboard shortcuts.
- **Multi-phase splits** (e.g. cross / F2L / OLL / PLL): press during a solve to record splits.
- **Manual entry mode** for stackmat users: type times (`1234` → 12.34, `1:02.34`, `DNF`, `+2`).
- **Display**: live, 0.1 s, whole seconds, or hidden while solving; 0.01 or 0.001 precision;
  focus mode hides everything but the clock while timing.
- **Scrambles**: real random-state scrambles where the WCA requires them, generated by solvers
  written for this project, in a background Web Worker. Next and previous, copy, edit or paste a
  custom scramble, scramble preview image for every event.

### Events

| Event | Scrambler |
|---|---|
| 3x3, 3x3 OH | Random state (Kociemba two-phase, ≤ 21 moves) |
| 3x3 BLD, Multi-BLD | Random state + random orientation (wide moves), no axis clash at the join |
| 3x3 FMC | Random state wrapped in `R' U' F` … `R' U' F` (axis rules enforced by the solver) |
| 2x2 | Random state, at least 4 moves, written as exactly 11 moves |
| Pyraminx | Random state, at least 6 moves, exactly 11 moves plus tips |
| Skewb | Random state, at least 7 moves, exactly 11 moves |
| Clock | Random state (WCA notation, no trailing pins) |
| 4x4, 4BLD | Random state (reduction solver, ≈ 48 moves; 4BLD adds x/y/z orientation) |
| 5x5, 6x6, 7x7, 5BLD | Random-move 60 / 80 / 100 (allowed by WCA 4b3e) |
| Megaminx | Pochmann random-move, 7 × 10 + U (allowed by WCA 4b3e) |
| Square-1 | Random state (shape BFS + parity-aware cube-shape search) |

**3x3 training subsets** (random state of the remaining pieces, solved into a scramble):
cross solved / F2L, last slot + last layer, last layer, ZBLL (edges oriented), PLL, OLL, CMLL
(Roux), L6E (Roux), corners only, edges only, EO solved (ZZ), and 2-gen `<R,U>`.

## 2. Statistics (WCA-correct)

- Single, mo3, ao5, ao12, ao25, ao50, ao100, ao200, ao500, ao1000 (all configurable),
  current and best, plus the session mean, σ and solve count.
- WCA rules: singles truncated to centiseconds, averages rounded. For aoN, trim ⌈5 %⌉ from each
  end (ao5 and ao12 drop 1 each, ao50 drops 3, ao100 drops 5). An average is DNF when DNFs
  exceed the trim. A mean is DNF on any DNF. Trim % is configurable.
- Rolling ao5 and ao12 columns in a virtualised solve list that stays fast at 100k+ solves.
- Solve detail: scramble with preview, date, splits, comment, penalty, copy, delete.
- Average detail: trimmed times in parentheses, copyable plain-text summary.
- **Stats page**: trend chart with rolling averages, histogram, PB progression, activity heatmap
  (practice calendar), time-of-day and weekday patterns, sub-X rate, and a table of every best
  average.

## 3. Sessions & data

- Unlimited sessions per event: create, rename, reorder, delete, merge, and move solves
  between them, from the session menu or the session manager (every session with its count).
- **Import from csTimer** (JSON export: sessions, times, penalties, scrambles, comments, dates).
- Export and import a full Facelet backup as JSON, and export a session as CSV.
- Offline-first PWA: installable, works with no connection.

## 4. Virtual cube (side feature)

- A hand-written WebGL renderer: rounded cubies, inset stickers, soft lighting, smooth eased
  turn animation, with no 3D library.
- **csTimer keymap**: I/K = R/R', J/F = U/U', H/G = F/F', S/L = D/D', D/E = L/L', W/O = B/B',
  U/M = r/r', V/R = l/l', T/Y = x, B/N = x', ; / A = y/y', P/Q = z/z', 5 / 6 = M, X / . = M',
  1/0 = S'/S, 2/9 = E/E', Z / / = d/d', , / C = u/u'.
- Mouse and touch: drag a sticker to turn a layer, drag the background to orbit.
- Space scrambles (random state) and starts optional inspection. The timer starts on the first
  turn and stops automatically when the cube is solved. Records time, moves and TPS.
- Solve replay with play, pause and speed controls.
- 2x2 to 5x5 supported. Configurable turn speed, camera and colours.

## 5. Algorithm trainer (side feature)

- Sets: **PLL** (21), **OLL** (57), **F2L** (41), **2-look OLL / PLL**, **COLL** (42),
  **ZBLS** (305), **ZBLL** (472, T/U/L/H/Pi/S/AS), **CMLL** (42).
- Every algorithm is machine-verified against the case it claims to solve. ZBLL algorithms are
  computed by an included search tool in finger-friendly move groups (`<R,U,D>`, `<R,U,F>`, `<R,U>`).
- Case images rendered from cube state: top view for last-layer sets (PLL with arrows), and an
  isometric view for F2L.
- Pick individual cases or whole groups. Track status (learning / learned).
- Training: random-state scrambles that set up the case (so the alg can't be read off the
  scramble), random AUF, a timed attempt, then the case and alg are revealed. Modes: random,
  weighted toward slow cases, recap (each case once), and a recognition quiz.
- Per-case stats (best, mean, count). Custom algorithm per case.

## 6. Tools

- Cross solver (all six colours, optimal), EOLine, Roux first block and 2x2x2 block solvers for
  the current scramble.
- Batch scramble generator (any event, N scrambles, copy or download).
- Metronome.

## 7. Customisation

A quick **Customize** panel beside the timer (Alt P) and Settings → Appearance:
- Theme: light, dark, or follow the system.
- Six palettes, or custom background and text colours for light and dark.
- An optional accent (presets or any colour). Monochrome is the default.
- Timer: font (Sans, Mono, Serif, System, seven-segment Display), size, weight, and hold / ready
  colours (fade, red / green, accent).
- Interface font, scramble font and size.
- Stats under the time and the next-best hint.
- Layout: session panel (left, right or hidden), tool dock, today line, OK / +2 / DNF bar.
- Focus mode.

Other preferences in Settings:
- Timer: hold time, inspection and alerts, update mode, precision, multi-phase, input method,
  stop key.
- Screen wake lock, haptics, start sound.
- Display: celebrations and milestones (with a PB minimum), reduced motion.
- Stats: which averages to show, list columns, trim %.
- Cube colour scheme, virtual cube speed and camera, trainer options.

Command palette (⌘K / Ctrl+K) and a full keyboard shortcut sheet (?).

## Engineering

- Svelte 5 + TypeScript + Vite. No UI framework, no chart library, no 3D library. Lazy-loaded
  routes, and solvers in a Web Worker.
- Pure-TS puzzle engines with unit tests (Vitest): cubie model, two-phase solver, every
  scrambler, statistics, the csTimer import.
- Static build, so it can be hosted anywhere (or opened from a local server).
